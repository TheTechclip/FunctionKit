# Security policy for @musecat/functionkit

> Scope: the published FunctionKit package and its documented integrations.

## Report a vulnerability

Email **heart@musecat.app** with the affected package version, reproduction steps, impact, and a minimal proof of concept when available.

## Disclosure

Do not disclose the issue publicly until maintainers confirm that a fix or mitigation is available.

## Scope

This policy covers `@musecat/functionkit` source and npm package releases. Report third-party dependency vulnerabilities to the upstream project as well.

## Response

We aim to acknowledge valid reports within 48 hours and provide status updates during triage.
